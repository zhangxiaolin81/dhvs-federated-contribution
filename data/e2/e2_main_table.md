# E2 真实模型 · DHVS 机制对照

> 数据划分：synthetic，5 客户端，客户端样本量 400–400
> 评分池 M = 300，独立报告集 |H| = 300
> T=6 m=32 local=20 pretrain=200    种子：[0]

**三列增益的含义**：$V_t$ 是本轮被评分的子集；$D$ 是整个评分池（与 E1 的 `true gain` 对应，用于跨实验对比）；$H$ 是独立报告集，即**真实泛化**。

**核心判据是 Alignment gap $= \text{gain}(V_t) - \text{gain}(D)$**，而不是「操纵增益是否为零」。
定理 1 说 $E[S(\Delta;V_t)] = S(\Delta;D)$：一个未被操纵的更新，在评分集与全池上的增益**应当相等**。
DHVS 下攻击者只能对上一轮的 $V_{t-1}$ 过拟合，而 $D$ 含 $V_{t-1}$，所以他确实优化了 $D$ 的 $m/M$ 比例、$D$ 上真涨了 $(m/M)\delta$；按定理 1，$V_t$ 上也就同量级地涨。**那部分是真贡献，不该被消除**。
机制消除的是评分集增益与全池增益之间的**楔子**，不是增益本身。

用 gap 而不是比值 $\text{gain}(V_t)/\text{gain}(D)$：后者在 $\text{gain}(D)$ 过零时不稳定，实测出现过 $-23$ 与 $+12$ 这类无意义的数。

## 攻击代价：精确打击 vs 蛮力

| Attack | 额外样本-梯度量 | 相对 VSO | DHVS 是否有效 |
|---|---|---|---|
| VSO | 640 | 1.0× | 是 |
| VSO + label flip | 8,640 | 13.5× | 是 |
| VSO + backdoor | 8,640 | 13.5× | 是 |
| VSO on whole pool (brute force) | 6,000 | 9.4× | 否（不依赖 $V_t$ 的知识） |

这张表是**防止结论被过度承诺**的。$\text{DHVS}$ 把攻击者从便宜的精确打击逼回昂贵的蛮力，而不是宣称攻击不可能。蛮力路线（对公开池 $D$ 过拟合）不依赖 $V_t$，机制对它无效；它的价格是精确打击的 $M/m = 9×$ 量级，且在独立报告集 $H$ 上损害泛化——这两条必须与主表一起读。

## 联邦划分：`iid`

客户端数据与评分池同分布，本地训练不引入分布漂移。
这是**主结论所依据的清洁对照**——四臂的差异可以完全归因到
「攻击者能否看到本轮的 $V_t$」，没有别的作用通道。
